Principe fondamental

Orbite ne collecte aucune donnée personnelle. Toutes vos données sont stockées exclusivement sur votre appareil. Aucun compte à créer, aucun serveur, aucune télémétrie.

Données stockées localement

Les données suivantes sont créées et conservées uniquement sur votre appareil, via la technologie SwiftData d'Apple.

Profils de bénéficiaires

Prénoms, alias, photos, dates de suivi. Ces informations ne quittent jamais votre appareil.

Notes de suivi

Texte, tags, signaux, dates. Les notes dictées sont transcrites directement sur votre appareil.

Objectifs et réseau

Objectifs éducatifs, contacts professionnels du réseau du bénéficiaire.

Journal réflexif

Entrées personnelles, humeurs, thèmes, auto-évaluations de pratique.

Événements et préférences

Calendrier de suivi, réglages de l'application.

Synchronisation iCloud

Si vous activez iCloud sur votre appareil, vos données Orbite peuvent être synchronisées entre vos appareils Apple via le service CloudKit d'Apple. Cette synchronisation est gérée par Apple selon sa propre politique de confidentialité. Orbite n'a aucun accès à vos données iCloud côté serveur.

Reconnaissance vocale

La dictée vocale utilise le Speech Framework d'Apple. La reconnaissance se fait prioritairement sur votre appareil (on-device). Dans certains cas, Apple peut traiter la reconnaissance sur ses serveurs selon sa politique de confidentialité.

Orbite n'enregistre pas, ne stocke pas et ne transmet pas vos fichiers audio. Seul le texte transcrit est conservé dans vos notes.

Données non collectées

Aucune collecte de données

Orbite ne collecte et ne transmet aucune des données suivantes :

Pas d'adresse email. Pas de données de localisation. Pas de cookies. Pas d'identifiants publicitaires. Pas de tracking analytique. Pas de partage avec des tiers. Pas de compte utilisateur.

Achats intégrés

Les abonnements sont gérés par Apple via StoreKit. Les informations de paiement sont traitées exclusivement par Apple selon sa politique de confidentialité. Orbite n'a jamais accès à vos informations de paiement.

Sécurité

Vos données sont protégées par le chiffrement natif d'iOS. Les éventuelles clés API (pour les fonctionnalités d'intelligence artificielle futures) seront stockées dans le Keychain sécurisé d'Apple.

Suppression des données

Vous pouvez supprimer l'ensemble de vos données à tout moment depuis les réglages de l'application. La désinstallation d'Orbite supprime toutes les données locales. Pour les données synchronisées via iCloud, vous pouvez les supprimer depuis les réglages iCloud de votre appareil.

Modifications

Toute modification de cette politique sera publiée sur cette page avec la date de mise à jour. Les changements significatifs seront signalés dans les notes de mise à jour de l'application.

Contact

Pour toute question relative à la confidentialité de vos données dans Orbite, vous pouvez contacter le développeur via l'adresse email indiquée sur la fiche App Store.
