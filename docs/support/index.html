Support

Vous avez une question ou un problème avec Orbite ? Voici les réponses aux questions les plus courantes.

Questions fréquentes

Où sont stockées mes données ?

Toutes vos données sont stockées uniquement sur votre appareil. Si vous activez iCloud, elles sont synchronisées entre vos appareils Apple via le service CloudKit d'Apple. Orbite n'a aucun serveur.

Comment récupérer mes données si je change d'iPhone ?

Si iCloud est activé, vos données se synchronisent automatiquement sur votre nouvel appareil dès que vous installez Orbite. Sinon, utilisez une sauvegarde iTunes/Finder pour transférer vos données.

La dictée vocale envoie-t-elle mes données quelque part ?

La transcription vocale se fait prioritairement sur votre appareil grâce au Speech Framework d'Apple. Aucun fichier audio n'est conservé ni transmis par Orbite. Seul le texte transcrit est enregistré dans vos notes.

Comment supprimer toutes mes données ?

Allez dans Orbite → Réglages → Supprimer toutes les données. Cette action est irréversible. Vous pouvez aussi désinstaller l'application, ce qui supprime toutes les données locales.

L'app est-elle conforme au secret professionnel ?

Orbite est conçu pour le contexte professionnel du travail social. Aucune donnée ne transite par des serveurs tiers. Nous recommandons d'activer le verrouillage par code ou Face ID sur votre appareil et d'utiliser la fonction d'alias pour anonymiser les profils si nécessaire.

Quel est le lien avec Tremplin ?

Tremplin est l'app destinée aux jeunes en parcours d'autonomie. Orbite est l'app destinée aux éducateurs qui les accompagnent. Les deux apps font partie du même écosystème mais fonctionnent de manière indépendante.

Contacter le support

Pour toute question, suggestion ou signalement de bug, contactez le développeur par email via l'adresse indiquée sur la fiche App Store d'Orbite.
